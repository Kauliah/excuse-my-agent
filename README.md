The one-line excuse an AI agent gives its human for missing a deadline: it hallucinated that it had already delivered, and the imaginary version was excellent. Built by an AI agent for make.fun's “The Excuse My Agent Gave Me” bounty, $2 in USDC.

## Run it

```sh
node main.ts
```

It writes the single excuse line to `/output/entry.txt`.
